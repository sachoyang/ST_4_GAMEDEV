## 검증한 최신 기술 사실 (재검색 불필요)

- **Unity GC는 Boehm-Demers-Weiser 방식** — .NET처럼 세대별이 아니고 **힙 압축도 안 함**.
  증분 GC는 작업을 여러 프레임에 나눌 뿐 총량을 줄이지 않음. → `02_CSharp.md` Q2-09
  **대부분의 지원자가 .NET 세대별 GC로 답하기 때문에 최대 차별화 포인트다.**
- **Unity 6.3 LTS**가 최신 LTS(2027-12까지), 6.0 LTS는 2026-10까지
- **Unity의 C# 언어 버전은 C# 9** (C# 10 미지원 → 문자열 보간 최적화를 못 받음)
- **CoreCLR 전환**: Unity 6.8(2026 예정)에서 Mono 제거 → 세대별 GC + 최신 .NET/C#
- **SRP Batcher는 드로우 콜 수가 아니라 렌더 상태 변경 비용을 줄임**
- `PriorityQueue<T,T>`는 .NET 6부터지만 **Unity(.NET Standard 2.1)에선 사용 불가**
